## 🔬 How It Works

### Pipeline Steps
1. **Data Generation** — 1,200 synthetic articles (600 real, 600 fake) with realistic linguistic patterns
2. **Preprocessing** — URL stripping, lowercasing, stopword removal, lemmatization
3. **Feature Engineering** — TF-IDF (5,000 unigrams + bigrams) + 7 linguistic features
4. **Model Training** — Logistic Regression, Random Forest, Gradient Boosting
5. **Evaluation** — Accuracy, Precision, Recall, F1, ROC AUC, confusion matrices
6. **Visualization** — 7 publication-quality charts + interactive HTML dashboard

### Linguistic Features
| Feature | Description | Fake News Pattern |
|---------|-------------|-------------------|
| `caps_ratio` | Fraction of ALL-CAPS words | High |
| `exclamation_ratio` | Exclamation marks per word | High |
| `sensational_score` | Density of alarm words | High |
| `credibility_score` | Density of attribution words | Low |
| `avg_word_length` | Average characters per word | Lower |
| `text_length` | Total word count | Variable |
| `question_ratio` | Question marks per word | Higher |

### Sensational Words (fake signal)
`shocking, exposed, breaking, urgent, truth, wake, deep state, agenda, silenced, secret, elites, patriots, deleted, hidden, bombshell`

### Credibility Words (real signal)
`according, study, research, published, confirmed, data, evidence, analysis, peer-reviewed, official, university, journal, researchers`

## 🔧 Extending the Project

### Use a real dataset
Replace `data/news_dataset.csv` with any CSV containing `title`, `text`, and `label` (0=real, 1=fake) columns. Popular public datasets:
- [LIAR Dataset](https://www.cs.ucsb.edu/~william/data/liar_dataset.zip)
- [FakeNewsNet](https://github.com/KaiDMML/FakeNewsNet)
- [WELFake Dataset](https://zenodo.org/record/4561253)

### Add more models
In `src/models.py`, add entries to the `get_models()` dict:
```python
from sklearn.svm import LinearSVC
"SVM": LinearSVC(C=1.0, max_iter=2000)
```

### Add deep learning
Swap TF-IDF for sentence embeddings using `sentence-transformers`:
```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(texts)
```
