## 🧠 Linguistic Intelligence Layer

The model doesn't rely on TF-IDF alone — it learns behavioral patterns commonly found in misinformation.

<div align="center">

| Feature                   | Fake News Signal | Strength |
| -------------------------- | :---------------: | -------- |
| 🚨 ALL CAPS                | High              | 🟥🟥🟥🟥🟥 |
| ❗ Excessive Punctuation    | High              | 🟥🟥🟥🟥⬜ |
| 🔥 Sensational Keywords    | High              | 🟥🟥🟥🟥🟥 |
| ❓ Rhetorical Questions     | High              | 🟥🟥🟥⬜⬜ |
| 📚 Credible References     | Low               | 🟩🟩⬜⬜⬜ |
