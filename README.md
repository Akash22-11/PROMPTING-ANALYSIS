## 🧠 Linguistic Intelligence Layer

The model doesn't rely only on TF-IDF.

It also learns behavioral patterns often found in misinformation:

| Feature                 | Fake News Signal |
| ----------------------- | ---------------- |
| 🚨 ALL CAPS             | High             |
| ❗ Excessive Punctuation | High             |
| 🔥 Sensational Keywords | High             |
| 📚 Credible References  | Low              |
| ❓ Rhetorical Questions  | High             |
